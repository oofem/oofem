
OOFEM Input Manual
==================

Authors: |author|

Version: |version|, Date: |today|

This manual is the reference for the OOFEM text input file: the order of the
records, the syntax of each record, and the meaning of every attribute.

If you have never written an OOFEM input file, start with
:ref:`anatomy-of-an-input-file`, which walks through a complete working file
record by record.  The rest of the manual is a reference: use the table of
contents or the search box to find the record you need.
