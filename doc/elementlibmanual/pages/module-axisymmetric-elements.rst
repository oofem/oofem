Axisymmetric Elements
=====================


Axisymmetric Elements
---------------------

Quadaxisym1ht element
~~~~~~~~~~~~~~~~~~~~~

Isoparametric four-node quadrilateral finite element for axisymmetric heat transfer
problems. The element description is similar to Quad1 element, see section
:ref:`Quad1ht`.

Tests/Examples: `tests/regression/tm/quadaxisym01.in
<https://github.com/oofem/oofem/blob/devel/tests/regression/tm/quadaxisym01.in>`_,
`tests/regression/tm/quadaxisym02.in
<https://github.com/oofem/oofem/blob/devel/tests/regression/tm/quadaxisym02.in>`_.

Traxisym1ht element
~~~~~~~~~~~~~~~~~~~

Linear triangular finite element for axisymmetric heat transfer problems. The element
description is similar to Tr1ht element, see section :ref:`Tr1ht`.

Tests/Examples: `tests/regression/tm/tmpatch44-1.in
<https://github.com/oofem/oofem/blob/devel/tests/regression/tm/tmpatch44-1.in>`_,
`tests/regression/tm/tmpatch44-2.in
<https://github.com/oofem/oofem/blob/devel/tests/regression/tm/tmpatch44-2.in>`_,
`tests/regression/tm/tmpatch44-3.in
<https://github.com/oofem/oofem/blob/devel/tests/regression/tm/tmpatch44-3.in>`_.
